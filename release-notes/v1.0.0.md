# Meet Quizzer 1.0

Turn the material you already have into focused practice—and see the source behind every answer. This is Quizzer's first stable release.

## Learn from your own material

- Import PDF, Markdown, and text documents into a library that stays on your device.
- Create multiple-choice, fill-in-the-blank, reasoning, and coding questions around your learning goal.
- Open the exact source citations behind generated questions instead of trusting an unexplained answer.

## Study your way

- Choose a fully local model, a signed-in coding agent, or your own API provider.
- Start quickly in Simple mode, or tune prompts, retrieval, providers, and spending limits in Advanced mode.
- Keep indexing, generation, unfinished quizzes, and practice history across restarts.

## Built for a dependable first release

- Resume interrupted generation without throwing away completed questions.
- Use signed update manifests and verified downloads on macOS, Windows, and Linux.
- Search documents with local full-text retrieval, with optional embeddings and reranking for deeper matching.

Thank you for trying the first official version of Quizzer.
